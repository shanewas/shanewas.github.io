Agentic Stealth Browser

Python and Playwright, v3.0.0 on PyPI, MIT

Browser automation for AI agents that holds up against bot detection: consistent fingerprints across TLS, navigator, WebGL and Canvas, human-like input, block detection with recovery, and an MCP server so agents can drive it directly.

Source on GitHub PyPI package

Edge Agent Bridge

Python and a browser extension, v2.5.0 on PyPI, MIT

Lets a script or an AI agent drive the Edge tab you already have open, so logins and VPN sessions survive. Commands travel over a local WebSocket with a 9 ms median round trip, and batching 50 actions runs 7.9 times faster than sending them one by one. No telemetry and no dependencies beyond Python 3.10.

Source on GitHub PyPI package
