Agent Browser Bridge

An open-source bridge between a local AI agent and the browser tabs you already have open. A Python daemon listens on 127.0.0.1 only; a browser extension (listed in the stores as Edge Agent Bridge) carries out snapshots, clicks, typing, uploads and screenshots in those tabs. Nothing leaves your machine.

Built and maintained by Shanewas Ahmed. MIT licensed.

Get it

  • Source and documentation: github.com/shanewas/agent-browser-bridge
  • Python package: pypi.org/project/edge-agent-bridge
  • Extension: Microsoft Edge Add-ons or the Chrome Web Store
