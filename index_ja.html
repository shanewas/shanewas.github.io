SkyPDF — 低レベルPDF基盤

RHEL上でC++ / C#により開発する低レベルPDFライブラリおよび暗号署名システム。エンタープライズのドキュメントワークフローを支える中核基盤。署名・レンダリング・変換のWebAPI設計、RPMパッケージングとCI/CDパイプラインの構築を担当し、重要APIのボトルネックを解消して本番環境でスループット2倍を達成。

C++ C# RHEL RPM WebAPI
株式会社スカイコムでの現在進行中の本番プロジェクト（非公開）

Agentic Stealth Browser

自律型エージェント向けのオープンソース・ステルスブラウザ自動化ライブラリ（Playwrightベース）。TLS・navigator・WebGL・Canvasにわたる一貫したフィンガープリント、人間らしい操作の再現、ブロック検知と復旧、AIエージェントから直接操作できるMCPサーバーを実装。PyPIでv3.0.0を公開、MITライセンス、pytest / ruff / mypy / CodeQL / Dockerスモークテストの全CIグリーン。

Python Playwright MCP Docker PyPI

GhostScrape — スクレイピングAPI（SaaS）

上記ステルスエンジンを基盤とする本番SaaS。APIキー認証・利用量計測・クォータ課金を備えたFastAPIサービスで、PostgreSQL 16とAlembicによるマイグレーション、ローテーティングプロキシ層を実装。Cloudflare Tunnel経由で公開し、systemdによるリソース制限と専用サービスユーザーで堅牢化したLinux上に配置。

FastAPI PostgreSQL Alembic Cloudflare systemd

Shanewas.PosixIpc

Linux上のSystem V共有メモリとセマフォを扱う軽量な.NETライブラリ。ネイティブバイナリを同梱せずlibcへのP/Invokeのみで実装し、同一ホスト上のプロセス間で低レイテンシなIPCを実現。NuGetで公開。

C# .NET Linux P/Invoke NuGet

Engram — マシン横断エージェントメモリ

コーディングエージェント向けの永続メモリ。プライベートGitリポジトリそのものを保存先兼監査ログとし、すべての事実を作成者・時刻付きでコミットとして記録、git revertで取り消し可能。データベースもサービスも不要。セッションフックがマシン間の同期を自動化し、同期対象はパス許可リストで限定。
