Agentic Stealth Browser

Python / Playwright、PyPIでv3.0.0を公開、MITライセンス

ボット検知に耐えるAIエージェント向けのブラウザ自動化ライブラリ。TLS・navigator・WebGL・Canvasにわたる一貫したフィンガープリント、人間らしい操作、ブロック検知と復旧、エージェントから直接操作できるMCPサーバーを備える。

GitHubのソース PyPIパッケージ

Edge Agent Bridge

Python / ブラウザ拡張機能、PyPIでv2.5.0を公開、MITライセンス

すでに開いているEdgeのタブを、スクリプトやAIエージェントからそのまま操作できるライブラリ。ログイン状態やVPNセッションを維持したまま自動化できる。ローカルWebSocketの往復は中央値9 ms、50アクションのバッチ実行は逐次実行の7.9倍高速。テレメトリなし、Python 3.10以外の依存なし。
